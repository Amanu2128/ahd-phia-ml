# ahd-phia-ml
# Identifying Advanced HIV Disease with Machine Learning — PHIA, 11 Sub-Saharan African Countries

Analysis notebook for the study "Predicting Advanced HIV Disease in Sub-Saharan
Africa Using Multi-Country Machine Learning Models", submitted to PLOS Global
Public Health.

## Contents

`ahd_analysis.ipynb` — variable screening, fold-specific imputation and scaling,
recursive feature elimination, training and tuning of five classifiers,
leave-one-country-out evaluation, and SHAP interpretation.

## Data

The PHIA survey datasets are not included here. They are held by the PHIA Project
and can be obtained at https://phia-data.icap.columbia.edu/ after registration and
approval of a data access request. The PHIA data-use agreement does not permit
redistribution.

To run the notebook, place the merged analytical dataset in the working directory
and adjust the file path in the loading cell.
